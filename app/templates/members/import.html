Select an Excel spreadsheet containing your church members. The file must be in .xlsx format.

Excel file format

Your first row must contain the column names below. Column names are not case-sensitive. You can download the ready-made template above.

✓ Name and Phone are required
Column Required? Example Description

SMS Opt In Optional Yes Yes or No
WhatsApp Opt In Optional No Yes or No

📱 Phone numbers

Phone numbers are used to identify existing members. If the same phone number already exists in your church, that row will be skipped instead of creating a duplicate.

👥 Groups

If you provide a group name, it must already exist as an active group in your church. Otherwise the member will still be imported but will not be assigned to that group.

💬 Communication preferences

For SMS Opt In and WhatsApp Opt In, use Yes or No. Other values will be treated as No.

👤 Member status

Every successfully imported member will automatically be created as an active member.

⚠️ Important

Please review your spreadsheet before importing. Existing members with the same phone number will be skipped. Imported members cannot be automatically undone.
